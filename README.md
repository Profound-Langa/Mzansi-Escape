# Mzansi Escape

Mzansi Escape is a collaborative 3D browser game inspired by South African cities and everyday urban life. It combines Three.js scenes, physics-based gameplay, and locally grounded level scenarios.

## My contributions

This is a team project. My contributions include NPC interactions and UI/HUD work, as well as gameplay and mission development for Soweto Homecoming, including its timed sandbag objective.

## Tech stack

- React and Vite
- Three.js and Cannon-es
- Firebase Authentication and Cloud Firestore

## Run locally

```bash
npm install
npm run dev
```

## Build and play a release (Windows)

Run `npm run release` to build the production game into the `release` folder. Then double-click **release/Run Mzansi Escape.bat**. Keep the launcher window open while playing; close it to stop the local game server.

The release requires Node.js and an internet connection for Firebase sign-in and saved progress.
